=== 1. What the device claims ===
  HAP_query_total_VTCM: page_size=8388608 page_count=1  -> total 8192 KB

=== 2. Single acquire: how much can one process actually get? ===
     1.000 MB ( 1048576 bytes) : OK   (acquire 62 us)
     2.000 MB ( 2097152 bytes) : OK   (acquire 24 us)
     4.000 MB ( 4194304 bytes) : OK   (acquire 26 us)
     6.000 MB ( 6291456 bytes) : OK   (acquire 24 us)
     7.000 MB ( 7340032 bytes) : OK   (acquire 22 us)
     8.000 MB ( 8388608 bytes) : OK   (acquire 23 us)
     8.000 MB ( 8388609 bytes) : FAIL (acquire 85 us)
     8.004 MB ( 8392704 bytes) : FAIL (acquire 69 us)
    12.000 MB (12582912 bytes) : FAIL (acquire 65 us)
    16.000 MB (16777216 bytes) : FAIL (acquire 67 us)

=== 3. Two simultaneous acquires of the same size ===
  2 x   1.0 MB (=   2.0 MB) : first=OK second=OK
  2 x   2.0 MB (=   4.0 MB) : first=OK second=OK
  2 x   4.0 MB (=   8.0 MB) : first=OK second=OK
  2 x   5.0 MB (=  10.0 MB) : first=OK second=FAIL
